# Javagotchi
#### A web application made with Spring Boot about a digital creature to care

### Purposes of this project:
- have fun with programming
- educational reference for beginners about Java, Spring Boot, Web applications 
- demonstration of useful human-machine collaboration as UI part of this project was carried out with the help of Claude.ai

### Quickstart
- Install JDK 25+
- Install Apache Maven
- Launch Javagotchi using command mvn spring-boot
- Visit http://localhost:8080
